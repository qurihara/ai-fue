暗号笛ウォレット

笛を吹くと、その場で秘密鍵が組み立てられ、自分の口座が現れます。鍵はどこにも保存されません。ページを閉じれば消えます。ネットワークは Polygon Amoy（テストネット）です。

デモンストレーション用です。本物の資産には使わないでください。
  • Amoy はテストネットで、そこのトークンに金銭的な価値はありません。
  • 笛が運ぶ秘密が小さいと、口座のアドレスから総当たりで秘密鍵に到達できます。カード1枚（約21ビット）は総当たりできる大きさです。価値のあるものを預けてよいのは128ビット級（スプール2枚）だけです。
  • ブラウザの拡張機能や画面の記録からは守れません。金額の大きい用途では専用の端末を使ってください。
笛を吹くにはマイクの許可が要ります。

1. 笛を吹いて口座を開く

「開始」を押して笛を順に吹きます。息を切るか音が変わったところで自動的に次の笛へ進みます。吹き終えたらもう一度押してください。
2枚組（2-of-2）の場合は、1枚目を確定してから2枚目を吹きます。2枚そろうまで口座は現れません。

受け取りは笛なしでできます。このアドレスを相手に伝えるだけです。送るときだけ笛が要ります。 テスト用トークンは Alchemyの蛇口 や QuickNodeの蛇口 から入れられます（Polygon公式の蛇口は終了しました）。
接続先（RPC） 繋がらないときは別の接続先を選んでください。どれもPolygon Amoy（chainId 80002）です。

3. 送る

まだ用意していません。次の段階で、この画面から署名して送れるようにします。いまは残高の確認までです。

鍵の作り方は flute_key.js（PBKDF2 60万回・salt は「版｜ラベル」）。音の復号は cipher_codec.js。設計の検討は DESIGN.md。外部のCDNは使わず、必要なライブラリは vendor/ に置いています。
