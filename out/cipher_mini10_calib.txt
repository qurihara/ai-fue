# CipherFlute mini10 外見統一版(uniform_flute)の較正。2026-07-28 の較正コーム36本からフィット。
# 12音(G#6..G7)を各3本、H2Dで印刷したコームを3回通して吹き、低音側8本は1本ずつ測り直した。
# 当てはめには設計値ではなく STL から実測した空洞の長さを使った。G#6 だけは外形の長さに
# 頭打ちされて設計より1.57mm短く、これを入れないと「G#6だけ異常に高い」という見かけの
# 音依存のずれが残る。実測長で当てはめると12音すべてが1つの式に乗る（残差 11.3 cent, 30本）。
# 各音の残差[cent]: G#6 -8.1 / A6 +8.0 / A#6 +8.1 / B6 -10.2 / C7 -2.6 / C#7 +16.9 /
#                   D7 -4.7 / D#7 -5.2 / E7 -0.0 / F7 +7.0 / F#7 +1.2 / G7 -5.1
# この較正では管長がどの音も約1.0mm長くなる（例: G7 は 36.93mm から 38.07mm へ）。
