# 秘密 260729（11進6桁 = 1,6,8,9,8,7）を、3台のうち2台で復元できるように分けた。
# 乱数の種は 20260730 で固定した（再現できるようにするため）。
#   python3 fue/threshold.py --secret 260729 -k 2 -n 3 --seed 20260730
#
# 台ごとの断片（記号6個）と、載っている笛の並び（先頭が基準笛C7）

#
# どの2台をそろえても 260729 が戻る。1台だけでは何も分からない。
# 台の番号は、正面の底板の左端に彫った数字（1/2/3）で見分ける。
# 吹き始めの笛は、足の先に＊が彫ってある左端の1本。そこから右へ9本を続けて吹く。
