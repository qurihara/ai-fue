# 2-of-3 の秘密分散を、3つの違う日用品で担う（2026-07-30）
#
# 秘密 124816（11進5桁 = 8,5,8,5,10）を3つに分け、どの2つでも復元できる。
# 1つだけでは何も分からない。乱数の種は 20260730 で固定した。
#   python3 fue/threshold.py --secret 124816 --width 5 -k 2 -n 3 --seed 20260730
#
# 3つとも笛8本（基準笛1＋断片の記号5＋パリティ2）でそろえた。
# パリティ2なので、途中の1本が鳴らなくてもその担体だけで復元できる。
#
# 断片1 … 箱（Chordikaのカードを収める枡箱の床に仕込む）
#   記号 6,7,1,2,1   笛 C7 G7 D#7 F7 G#6 A#6 C#7 D#7
#   設計 out/cardbox_v1_share1.3mf   印刷 out/cardbox_v1_share1_a1m.gcode.3mf
#   A1 mini・PETG・252層・4時間27分・42.8g・解凍2.22MB
#   吸込口は短辺の外面に8つ並ぶ。窓は箱の内側（真上）へ開くので、カードを入れたままでは吹けない。
#   番号「1」は吸込口が並ぶ短辺の外面に彫ってある。
#
# 断片2 … カード（クレジットカード大・財布に入れて持ち歩く）
#   記号 4,9,5,10,3  笛 C7 F7 D#7 A6 G#6 C7 F#7 G7
#   設計 out/cipher_card_v4_share2.3mf   刻印「2of3 #2」
#
# 断片3 … 本立て（底板だけに笛・部屋に置いて動かさない）
#   記号 2,0,9,7,5   笛 C7 D#7 E7 D7 A#6 E7 C#7 C7
#   設計 out/bookstand_v4_share3.3mf   番号「3」は正面の底板の左端
#   開始笛は左端の1本（足の先に＊）。そこから右へ8本。
#
# 読むURL（記号モード・パリティ2）
#   https://qurihara.github.io/ai-fue/cipher/#hi=G7&norepeat=1&mode=symbols&parity=2&pitchsplit=1&splitcents=80
#
# 復元の確認（理想周波数で往復）
