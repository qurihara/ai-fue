# LaTeX版の論文は別リポジトリへ移した

2026年8月4日。WISS 2026へ投稿するLaTeX版の原稿は、このリポジトリから切り出して
専用のリポジトリへ移した。**このフォルダにLaTeX版は無い。**

- 置き場　`../../cipherflute-wiss2026/`（共有フォルダ内、ai-fue と並ぶ）
- GitHub　https://github.com/qurihara/cipherflute-wiss2026 （**非公開**）

## なぜ分けたか

Overleafのgithub連携はリポジトリ全体を同期し、サブディレクトリだけを選ぶことが
できない。ai-fue は作業ツリーが445MB、追跡ファイルが1,271件（`out/` だけで315MB）
あり、そのままでは繋げない。論文だけの小さなリポジトリ（1.3MB、20ファイル）に
分けた。

**編集は移した先だけで行うこと。** 両方に置くと必ず食い違う。

## このフォルダに残っているもの

LaTeX版へ移る前の資料は、すべてここに残してある。

- `cipherflute_wiss2026_v1.2.docx` ほか　Word版の原稿（v1.2まで）。生成器は
  `make_paper_wiss_v12.py`。**LaTeX版は白紙から書き直したので、内容は引き継いで
  いない**（論旨の重心が「秘密の物理バックアップ」から「読み出しに機械が要らない
  こと」へ変わった）
- `cipherflute_wiss2026_v2_draft.md`　LaTeX版のもとになったmarkdownの第2稿。
  役目を終えており凍結してある
- `figs/`　実物の写真の原版。LaTeX版には切り出して縮めたものを置いてある
- `wiss2026_tmpl/`　公式テンプレートを展開したもの（書き方の参考）
- `WISS2026_Template_oral.zip`　公式テンプレートの原本
