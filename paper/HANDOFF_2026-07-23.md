# CipherFlute 引き継ぎ情報（2026-07-23）

## 0. これは何か
CipherFlute＝秘密情報を3Dプリントの笛に符号化し、吹いた音をスマホのマイクで復号する電源不要の物理バックアップ。
日用品に偽装して「どこに秘密があるか分からない」形で仕込む。秘匿は音響でなくデジタルのShamir秘密分散が担う（音響層の秘匿寄与は0ビットと会計）。

## 4. 次にやること（優先順）
1. 物理の往復試験（実機実証）: out/cipher_roundtrip_demo.stl を mini10でH2D（GUI手動・PLA Pure・ブリム）に印刷 → 5本を左から順に吹く → https://qurihara.github.io/ai-fue/cipher/ で復号 → 照合子 a9415803… と一致すれば「秘密を入れて→吹いて→取り出す」通しが実機で実証。刷ったコームが目標周波数に乗るかで較正A=86718も同時確認。
   - 目標周波数[Hz]: C7=2093, G#6=1661, F#6=1480。
2. 手順4＝外見統一（内部壁でボアを隠す・偽装の核）: mini10で内部壁の音下がりを測り直す。死んだ空洞のバネ対策の変種を1コームで比較（(a)密閉厚壁2-3mm＝第一候補 /(b)末端解放＝栗原案・壁が漏れると長さ隠しを壊すリスク /(c)現行密閉薄壁）。幾何での先取り補償（今日halfcut.pyに実装したWALL_FLAT_MAX/TAU＝旧ヘッド用なので要再測定）は保険。
3. 温度の打ち消しの実証: 暑い条件待ち。涼しい側25.3度は取得済み。暑い日に同じ5本を中庸で6回吹き、C7基準の比が不変か（絶対値は上がるが比は不変）を見る。
4. 秘密分散・公開鍵の本実装（ハッシュ照合→Shamir/公開鍵・ブロックチェーン固定）。折り返し配置（128ビット≈50本を格子に）。素材はPLA Pure標準、長期はPETG/金属を展望。
