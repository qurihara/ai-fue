== 手順1：各笛の単独確認 ==
詰めたコーム cipher_close4（G#6/A6/A#6/B6、予測 1662/1760/1863/1975 Hz）2周
  1664 / 1758 / 1863 / 1963 Hz（1周目）
  1664 / 1758 / 1863 / 1980 Hz（2周目）
広いコーム cipher_wide5（F6/G6/A6/C7/D7、予測 1396/1568/1760/2091/2350 Hz）2周
  1400 / 1570 / 1764 / 2092 / 2332(+2672) Hz（1周目）
  1418 / 1570(+1869) / 1770 / 2074 / 2344 Hz（2周目）

手順1のセント誤差（各笛の最も素直な読み）
  G#6 1662→1664 +2 / A6 1760→1758 -2 / A#6 1863→1863 0 / B6 1975→1980 +4
  F6 1396→1400 +5 / G6 1568→1570 +2 / A6 1760→1764 +4 / C7 2091→2092 +1 / D7 2350→2344 -4
  吹圧による振れ：B6 は -11〜+4、F6 は +5〜+27、C7 は -14〜+1、D7 は -13〜-4
倍音の観察：低い笛（F6・G6）は 3f・5f が立ち 2f が出ない（奥の閉じた管の奇数倍音の兆候）。
           高い笛（A#6・C7・D7）は 2f も出る。過吹の飛び先（2f か 3f か）は手順5で確定する。

== 手順2：まとめて吹いたときの同時発音 ==
詰めたコーム4本まとめて
  基音2本(1752,2033) / 基音2本(1752,2033) / 基音1本(1770) / 基音1本(1758) / 基音1本(1764)
  → ほぼ A6(約1758) 主体。4本が4つの山には分かれない。
広いコーム5本まとめて
  基音2本(1535,2068) / 基音2本(1740,2074) / 基音2本(1553,2080)
  基音3本(1348,1758,2080) / 基音3本(1359,1764,2086)
  → 最良で3本（F6・A6・C7＝1つおきに離れた3本）が同時に立つ。5本全部は立たない。

栗原さんの所感：まだ口に一度に含めることはできそう。ただし笛によって最適な吹圧が違いそう。

== 解釈（速報）==
手順1は完全合格。全9本が予測周波数の近く（素直な読みで±5セント、吹圧込みでも±27セント以内）で鳴った。
H2Dで作った較正式 f=91891.5/(L+14.23) が A1 mini・黒PLA・0.08mm でもそのまま当たった。
詰めたコームの半音差4本が単独では±4セントで読めた＝半音スロット（12スロット/オクターブ）は読み取り可能。
同時発音は現状2〜3本まで。律速は注入同期より先に「笛ごとの最適吹圧の違い」らしい（立つのは離れた笛）。
手順3（歌口を1つずつ塞ぐ）で圧の問題か引き込みかを切り分ける。手順5（吹圧スイープ）でσ_差動と過吹の飛び先を出す。
