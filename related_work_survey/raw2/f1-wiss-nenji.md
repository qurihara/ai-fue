# WISS（インタラクティブシステムとソフトウェアに関するワークショップ）年次走査 2014年から2025年

対象研究はCipherFluteである。投稿先であるWISSの過去12年分の予稿集を年ごとに開き、掲載されている全発表の題名一覧を取得して、デジタルファブリケーションと3Dプリント、音と音響と楽器、物体の識別とタグと標識、秘密と暗号と認証、隠蔽とステガノグラフィ、電源を持たない物体を使う入力や出力の6つの観点から関連発表を拾い出した。

## 1 走査の方法

トップページ https://www.wiss.org/ から過去のワークショップと予稿集への一覧を取得し、2014年から2025年までの予稿集の目次ページが次の統一形式で存在することを確認した。

- https://www.wiss.org/WISS2014Proceedings/ から https://www.wiss.org/WISS2025Proceedings/ まで、12年すべてが HTTP 200 で取得できた。

目次ページのHTMLを機械的に解析し、`class="title"` と `class="authors"` の対で全エントリを抽出した。抽出件数と著者欄の件数が12年すべてで完全に一致したので、取りこぼしはないと判断した。予稿本体のPDFへのリンクも同時に抽出し、本稿で言及する全40件以上のPDFのURLに対して個別にHTTPステータスを確認し、すべて200であることを確かめた。

なお2014年の目次は `oral/032.pdf` のような通し番号形式、2015年から2019年は `oral/08.pdf` と `demo/1-A02.pdf` の形式、2020年から2023年は `data/08.pdf` の形式、2024年と2025年は `data/paper/23.pdf` と `data/demo/1-C30.pdf` と `data/international/26.pdf` の形式であった。年によってURLの形式が違うため、年ごとに実際のリンクを取得して用いた。

所属の表記は予稿集の目次に書かれた略記（東大、明治大、はこだて未来大など）を、標準的な正式名称に開いて記した。

### 2014年（掲載83件、関連5件）

セッション構成は音と音楽、ビジュアルデザインと制作支援、文字、ウェアラブルインタフェース、入力、人と社会の6つと、デモとポスター発表であった。

**（1）CapacitiveMarker: 静電パターンを内包した接触認識可能な2次元コード**
- 著者と所属: 池田昂平、塚田浩二（公立はこだて未来大学）
- 発表形式: デモとポスター発表 2A-01
- URL: https://www.wiss.org/WISS2014Proceedings/demo/097.pdf
- 内容（本文を読んで確定した）: 光学的なARマーカーを印刷したシール紙と、導電性の静電パターンを印刷した透明フィルムを2枚重ね合わせた40ミリメートル四方の2次元コードである。静電パターンは銀ナノインクを用いたインクジェット印刷で作り、周辺部に直径10.0ミリメートルの固定点を3点、中央部に直径8.0ミリメートルの可変点を1点配置し、太さ1.0ミリメートルの導電線で結ぶ。固定点3点でマーカーの位置と向きを検出し、固定点と可変点の相対位置で識別子を読む。作成したパターンは9種類である。シール紙の厚さは約0.1ミリメートル、透明フィルムの厚さは約0.13ミリメートルである。端末から離すとカメラでARマーカーとして認識され、タッチパネル上に置くと静電マーカーとして認識される。課題として静電マーカーの認識精度と、カメラでもタッチパネルでも認識できない10センチメートル以上の空白域の存在を挙げている。
- CipherFluteとの関係: 電源も電子部品も持たない受動的な物体に符号を持たせ、それを既存の民生機器で読むという構図が共通する。ただし語彙は9通りにとどまり、誤り訂正も基準体による正規化も導入していない。読み出しの物理はあくまで光と静電容量であり、音は使わない。前段の調査で「本文を読めていない」とされていた1件目であり、確認の結果、CipherFluteの符号設計（13スロット、1本あたり約3.7ビット、40本から49本で128ビット）とは桁が違う小規模な識別子であって、主要な主張を崩すものではないと判断した。ただし「日用品の外観を保ったまま情報を仕込み、専用装置を使わずに読む」という思想の先例として引用する価値がある。

## 5 WISSに存在しなかったこと

全1197件の題名を通読し、さらに次の語について機械的に全題名を検索した。暗号、秘密、分散、ステガノ、透かし、秘匿、隠蔽、ブロックチェーン、ウォレット、資産、署名、偽造、真贋、誤り訂正、笛、リコーダである。

その結果、2014年から2025年までのWISSの予稿集には次のものが1件も存在しなかった。

- 暗号という語を題名に含む発表が1件もない。暗号技術、暗号プロトコル、カードベース暗号を扱った発表は12年間存在しない。
- 秘密、秘匿、秘密分散を題名に含む発表が1件もない。したがってShamirの秘密分散のような閾値秘密分散を物理媒体に載せる研究はWISSに存在しない。
- ステガノグラフィ、電子透かし、透かしを題名に含む発表が1件もない。隠蔽を扱った発表は2022年の画面共有時のプライベート情報の視覚的隠蔽の1件、隠すを扱った発表は2024年のHidEye（片目を隠す動作によるインタラクション）の1件のみであり、いずれも物理造形への情報の隠し込みではない。
- ブロックチェーン、暗号資産、ウォレット、リカバリーシードを扱った発表が1件もない。したがって暗号資産の復元用情報を物理媒体へ保管するという用途はWISSでまったく手つかずである。
- 誤り訂正符号を題名に含む発表が1件もない。符号理論を物理造形の設計に持ち込んだ発表は見つからなかった。M系列を使った2017年の円筒バーコードが、系列の数学的性質を符号設計に使った唯一の例である。

- 認証を題名に含む発表は12年間で4件（2014年FingerPhone、2015年i/k-Contact、2015年打ち間違え許容パスワード、2016年マイクロ生体認証、2023年ドアノブ開扉ジェスチャ。認証という語を含むものを数えると5件）にとどまり、いずれも生体情報または行動特徴に基づく確率的な照合であって、秘密の完全な復元を扱ったものはない。

以上を総合すると、次の主張はWISSの過去12年の予稿集に照らして成立する。すなわち「電源も電子部品も持たない造形物に、符号語彙として設計された多数ビットの秘密を格納し、誤り訂正と基準体による正規化を伴って人が吹くだけで読み出す」という研究は、WISSに一度も現れていない。近接するのは、造形物の内部構造を能動音響センシングで識別する系統（2019年の久保ら、2021年の髙倉ら、2017年の片倉ら）と、物理的な周期構造をIDに写す系統（2017年の奥山ら、2025年の瀬崎ら、2025年の林ら）の2つであり、いずれも少数クラスの識別にとどまり、符号システムとしての設計層を持たない。

## 6 残った穴

- 76件を関連ありと判定したが、本文を取得して確認したのは22件である。とくに2016年と2018年は関連候補（それぞれ7件と6件）の本文をまったく読んでいない。この2年は高橋治輝と宮下芳明による熱溶解積層方式の造形挙動の研究が集中しており、CipherFluteの造形上の主張（厚さ4ミリメートル、幅7ミリメートル、サポート材なし平置き）を支える国内先行研究がここに埋もれている可能性がある。
- 2022年の「南京錠を例としたFigmaを用いたexUI設計手法の検討」と2023年の「日用品の挙動を記録／活用するスマートステッカー」と2024年の「Lithophane造形システム」は、それぞれ錠、日用品への情報付与、造形物の厚み分布への画像の隠し込みという観点で関連しうるが、本文を読めていない。
- WISSの予稿集の目次には査読コメントへのリンク（`oral/8.html` の形式）が併記されている年がある。査読コメントには近接研究の指摘が書かれていることがあり、CipherFluteが同じ指摘を受ける可能性を予見する材料になるが、今回は読んでいない。

- WISSと対をなす国内会議であるインタラクション（情報処理学会）は今回の対象外である。前段の調査でも2018年、2024年、2025年しか通せていないと報告されており、2014年から2023年のインタラクションのプログラムは依然として未走査である。久保らがFabAuthの関連研究として引用していた岩瀬らの「アクティブ音響センシングによる日常物体認識と位置推定」（インタラクション2018論文集、62ページから71ページ）はその一例である。
